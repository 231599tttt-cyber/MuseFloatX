# 一键启动 / 重启包（Windows，Python venv 路线）

给你自己的那份一键包，现在也打包到公开仓库里了，别人不用再让豆包重新做，直接下载这两个文件就能用。

## 里面有什么

- `启动服务.bat`：双击就能跑起 18610 端口服务；
- `重启服务.bat`：服务在跑时双击，会先停掉旧进程再重起。

两个文件内容特意只用英文，避免乱码。

## 怎么用

1. 把这两个 `.bat` 文件放到你电脑上的 muse2api 文件夹本体里，不要只放桌面；
2. 在每个文件上右键 → “发送到 → 桌面快捷方式”，桌面上就会有两个快捷方式；
3. 开机后双击桌面的“启动服务”，弹出来的黑窗口不要关，服务就一直在跑；
4. 服务在跑时想重启，双击桌面的“重启服务”就行；
5. 想开机自启，把“启动服务”的快捷方式复制到 `shell:startup` 文件夹里，这一步由你自己决定要不要做。

## 注意

- 这两个文件是 Python venv 路线，假设你已经按 TUTORIAL.md 建好了 venv、装好了依赖，服务是用 `uvicorn app:app --host 0.0.0.0 --port 18610` 跑的；
- 如果你用的是 Docker 路线，不要用这两个文件，用 Docker 的启动方式；
- 电脑关机、休眠、黑窗口关了，服务就停了，重新开机后双击“启动服务”就能恢复。
