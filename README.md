# MuseFloatX（X 悬浮回复助手，第 38 版）

只在 X 里用的悬浮回复助手：复制帖子、点悬浮球、生成回复建议，你自己复制粘贴，**不自动发送**。

## 第 38 版流程（剪贴板版）

1. 在 X 里复制一条帖子；
2. 点悬浮球，面板先出来，再自动读一次剪贴板，读到就直接生成；
3. 面板显示当前帖子（带边框的框框里，最多显示 300 字预览，全文用于生成）和 AI 回复；
4. 风格就是按钮：自然 / 幽默 / 简短，点哪个就按哪个生成一次；生成中点另一个风格是先取消当前那一通、再换风格重来，不是叠加；生成中点已选中的风格直接忽略；
5. 点“复制”后你自己去 X 粘贴，点“重新生成”只对当前原文再生成一次，不重读剪贴板。

不需要无障碍，不截图，不 OCR，不后台持续监听剪贴板。没复制就点球，面板会提示先复制再点球；自动读不到时，关面板、重新复制、再点球。

系统提示词（第 38 版）：`你是一个回复助手。根据这个内容，自然地/幽默地/简短地回复。`，无字数限制，Muse 不用每次想着控制字数。

## 功能

- X 页面悬浮球，可拖动、松手自动贴左右边
- 悬浮面板：当前帖子框、风格按钮（点中不灰）、AI 回复、复制、重新生成、关闭
- 生成中重复提交会被代码挡住，只提交一次、生成一次、传输一次，流式失败不再自动发第二通兜底
- 帖子文字只放内存，不写磁盘，不外发到你配置的服务地址之外

## 编译

需要 JDK 17 + Android SDK（platforms;android-34、build-tools;34.0.0）：

```bash
export ANDROID_HOME=$HOME/android-sdk
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

首次编译需要联网下载 Gradle 与依赖。本仓库已有 GitHub Actions 工作流，推到 main 后会自动编译 debug APK。

## 使用

1. 安装 APK，打开 App，先看主页版本号。
2. 开悬浮窗权限（在 App 里点按钮跳转到系统设置里开）。
3. 在“AI 服务”里填一次：服务地址、API 密钥、模型，点“测试连接”通过后再用。密钥永远不要写进代码里，只在 App 里填。
4. 点“启动悬浮球”，按上面第 38 版流程用。

服务地址换了不用重编 APK：直接在 App 设置里改地址就行。电脑 IP 变了（比如热点重开）也是这样改。

## 服务端部署（二选一）

App 本身不带模型，它只调你自己部署的 OpenAI 兼容服务（`POST {服务地址}/v1/chat/completions`，Bearer 密钥）。

### 方案 A：开源模型（推荐，无账号风险）

电脑或 VPS 上装 Ollama，跑同一个 GGUF 模型，手机和电脑都能用：

- 首选：Qwen2.5-3B-Instruct，Q4_K_M，约 2.1GB
- 降档：Qwen2.5-1.5B-Instruct，Q4_K_M，约 986MB
- 上下文只开 512 到 1024 token 就够了，X 回复是单轮，不需要对话记忆

Ollama 默认端口是 11434，App 里服务地址填 `http://你的服务器IP:11434`，模型填你拉下来的模型名。

### 方案 B：muse2api（你自己电脑上已有服务时）

Muse（muse.ai）目前没有公开的官方 API，所以 App 里**没有“Muse 一键登录、装好就能用”**这种做法。如果你自己部署了 muse2api，把它的服务地址（默认端口 18610）和密钥填进来就能调通。

App **不做**以下事：不抓取 Muse Cookie、不做导号、不做账号池、不做自动登录、不替你建服务器、不在服务器上托管别人的账号。请不要把 Muse 账号密码、Cookie 或密钥发给任何人，也不要把服务地址公开暴露。

风险提示：第三方逆向封装服务可能违反平台条款、导致账号受限或服务不稳定，请自行评估；生成内容请你自己检查后再粘贴发送。
