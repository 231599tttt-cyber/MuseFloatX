# MuseFloatX（X 悬浮回复助手）

只在 X（Twitter）里用的悬浮回复助手：点悬浮球识别当前帖子，生成回复建议，你自己复制粘贴，**不自动发送**。

## 功能

- X 页面悬浮球，可拖动、松手自动贴左右边
- 点击悬浮球自动识别当前帖子文字（无障碍节点优先；读不到时可用截图识别，本机 OCR，不上传截图）
- 悬浮面板直接显示 AI 回复，支持复制、重新生成、重新识别
- 三种风格：自然 / 幽默 / 简短；回复语言与帖子语言保持一致（中文、英文及其他语言）
- 屏幕文字只放内存，不写磁盘，不外发到你配置的服务地址之外

## 编译

需要 JDK 17 + Android SDK（platforms;android-34、build-tools;34.0.0）：

```bash
export ANDROID_HOME=$HOME/android-sdk
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

首次编译需要联网下载 Gradle 与依赖。

## 使用

1. 安装 APK，打开 App。
2. 开两个权限：悬浮窗、无障碍（在 App 里点按钮跳转到系统设置里开）。
3. 在“AI 服务”里确认一次：服务地址和模型在最终版里会预先填好（Windows 电脑 + 同 WiFi 路线：地址就是电脑的局域网 IP:18610，模型是 `muse-spark`），你只需要填一次密钥，点“测试连接”通过后再用。
4. 点“启动悬浮球”，打开 X 看一条帖子，点悬浮球，面板里看回复，点“复制”后去 X 粘贴。

预填地址的改法（给以后换电脑 IP 时用）：改 `DefaultEndpoint.kt` 里的 `BASE_URL`，重新编译即可；密钥永远不要写进代码里，只在 App 里填。

## 关于 Muse 接入（请先读）

Muse（muse.ai）目前没有公开的官方 API，所以 App 里**没有“Muse 一键登录、装好就能用”**这种做法。

App 用的是通用 OpenAI 兼容接口（`POST {服务地址}/v1/chat/completions`，Bearer 密钥，模型名默认 `muse-spark`）。如果你自己部署了 muse2api，把它的服务地址和密钥填进来就能调通；如果你用别的 OpenAI 兼容服务，同样填地址和密钥即可。

App **不做**以下事：不抓取 Muse Cookie、不做导号、不做账号池、不做自动登录、不替你建服务器。请不要把 Muse 账号密码、Cookie 或密钥发给任何人，也不要把服务地址公开暴露。

风险提示：第三方逆向封装服务可能违反平台条款、导致账号受限或服务不稳定，请自行评估；生成内容请你自己检查后再粘贴发送。
